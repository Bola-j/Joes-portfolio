# Youssef Medhat Portfolio

A responsive, single-page portfolio site for Youssef Medhat, a branding and visual-identity designer. The site presents selected case studies, design services, professional philosophy, and contact links.

## Technology

- Semantic HTML with accessibility landmarks and a skip link
- Modular CSS split into tokens, base styles, components, and page sections
- Vanilla JavaScript interactions
- Local image assets plus Google Fonts

## Run locally

The site is static and needs no build tooling. Open `index.html` in a browser, or use any static server:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Structure

```text
index.html   Page content and semantic structure
css/         Design tokens, base styles, components, and sections
js/          Client-side interactions
images/      Portfolio image assets
assest/      Additional project assets
```
